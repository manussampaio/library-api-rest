# API Biblioteca

API para gerenciamento de uma biblioteca e seus empréstimos de livros.

## Tema

Tema 2: Biblioteca e empréstimo de livros.

## Entidades

- **Livros:** cadastro e gerenciamento dos livros.
- **Usuários:** cadastro e gerenciamento dos usuários.
- **Empréstimos:** registro e devolução de livros.

## Funcionalidades

- Cadastrar, listar, atualizar e remover livros.
- Cadastrar, listar, atualizar e remover usuários.
- Registrar empréstimos.
- Realizar devoluções.
- Consultar empréstimos.
- Verificar livros disponíveis.
- Verificar empréstimos atrasados.

## Regras

- Só é possível emprestar um livro se houver exemplar disponível.
- Cada usuário pode ter no máximo 3 empréstimos ativos.
- Usuários com empréstimos atrasados não podem pegar novos livros.

## Tecnologias

- Node.js
- Express
- JavaScript
